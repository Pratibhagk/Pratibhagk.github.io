# Personal website starter — GitHub Pages

## Fast setup (no command line required)
1. Create a **public** GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. In the repository, choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `.nojekyll` from this folder. (Do not upload the zip itself.)
4. Click **Commit changes**.
5. Under **Settings → Pages**, choose **Deploy from a branch → main → / (root)** and save.
6. Open `https://YOUR-GITHUB-USERNAME.github.io/` after publishing completes.

## Personalize before sharing
Search `index.html` for `Your Name`, `YOUR NAME`, `https://www.linkedin.com/`, `https://github.com/`, and `you@example.com`. Replace each placeholder with your real details. Update the education line and bio as you like. Edit `resources` in `script.js` to curate the discoveries.

## Notes
- This is a purely static site: no Flask/Python, backend, database, subscription, or API key.
- The featured resources open on third-party sites in a new tab.
- Once you have your final public URL, generate the bookmark QR code and test on multiple phones before printing.
- Later, Hugo can replace this site at the same URL. Keep your GitHub username/repository and site URL unchanged.
